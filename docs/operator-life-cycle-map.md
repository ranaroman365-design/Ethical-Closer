# ETC Operator Life Cycle Map (OLCM) — V1

**Status:** Canonical · Non-Destructive · Visualization Layer
**Stack Position:** Layer 10 of the ETC Architecture (Final)

---

## 🎯 Objective

A single, unified end-to-end map of the ETC journey **L0 → L8** that integrates existing KPI thresholds, commission structure, OSS, and PSP into one legible narrative.

> Each Level = Role + KPIs + Earnings + Behavior

## 1️⃣ Full Life Cycle (Canonical Nodes)

| L | Role | Focus | Primary KPI | Earnings (range) | Goal |
|---|------|-------|-------------|------------------|------|
| L0 | Applicant | Entry | Show + Close | — | Accepted into system |
| L1 | Trainee | Learning + Activation | Activity / task completion | none / minimal | Become active |
| L2 | Setter | Pipeline creation | Booked calls | €200 – €1,000 | Generate pipeline |
| L3 | Advanced Setter | Optimization | Show rate, qualification quality | grows with efficiency | Prepare for closing |
| L4 | Junior Closer | Revenue generation | Close rate + deals | €1,000 – €5,000 | Prove revenue capability |
| L5 | Closer | Scaled revenue | Volume + consistency | €5,000 – €12,000 | Consistent high income |
| L6 | Operator | Ownership (LP, budget, funnel) | Full funnel | €10,000 – €25,000+ | Run profitable unit |
| L7 | Director | Portfolio management | Aggregate performance | system-level | Scale multiple units |
| L8 | Partner | Expansion (B2B) | Strategic growth | highest leverage | Expand system externally |

Earnings ranges are **representative envelopes** sourced from the existing commission tables — never override.

## 4️⃣ Visual Structure

Horizontal journey: **L0 → L1 → L2 → L3 → L4 → L5 → L6 → L7 → L8**.
Each node is clickable and reveals: KPIs · Earnings · Requirements · Tools unlocked.
